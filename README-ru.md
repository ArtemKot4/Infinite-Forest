# ВЕТКА CONCEPTS — ТОЛЬКО ДЛЯ ПРОШЕДШИХ ИГРУ

Если вы НЕ играли в Infinite Forest — немедленно закройте эту ветку.

## ЧТО ЗДЕСЬ

Эта ветка содержит:

- Полную историю мира

- Описание всех концовок

- Механики репутации, проклятий, секретного биома

- Тексты всех записок (включая финальные)

- Лор, который должен открываться ИГРОКОМ, а не читаться на GitHub

- Здесь нет кода. Только концепции, сюжет и спойлеры.

## ДЛЯ КОГО ЭТА ВЕТКА

- Для тех, кто уже прошёл Infinite Forest и хочет понять, как всё устроено

- Для разработчиков, которым интересна архитектура нарратива

- Для теоретиков, которые хотят обсудить лор

## ЕСЛИ ВЫ НЕ ИГРАЛИ

Вы украдёте у себя:

- Первое чувство тревоги, когда лес зашептал

- Финал, который вы выбрали сами, а не прочитали на GitHub

- Секреты, которые скрыты за древними корнями

- Не делайте этого. Лес не прощает тех, кто заглядывает в конец, не пройдя путь.

## ПРЕДУПРЕЖДЕНИЕ

«Ты читаешь то, что должен был узнать сам. Лес молчит. Но я — нет. Закрой ветку. Иди играть. А потом возвращайся. Если захочешь.»
