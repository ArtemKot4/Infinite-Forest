# Секретный биом
Секретный биом сгенерируется только в случае идеального прохождения игры на хорошую концовку.

В нём будет генерация мода из 2018 мода на inner core. Всё: домики, деревья, рельсы, фонтаны.

Приведут туда игрока огоньки, если он последует за ними.

По сути секретный биом это то, каким лес был в самом начале, как буквально, так и в плане сюжета: до проклятий.

В этой папке находятся json из старой версии мода и код для генерации.
